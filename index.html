Selected work

Certificate automation

adidas · cert-manager, Venafi, Helm, Kubernetes
100+ certs · zero missed renewals
THE PROBLEM

TLS, Kafka, ingress and domain certificates across dev, SIT, staging and production were requested and renewed by hand and tracked in spreadsheets. Ops had missed 10–20 renewals over time, usually found by users first.

WHAT I DID

Deployed cert-manager with Helm in every namespace and wired it to Venafi, so the security team's approval flow stayed in place. Teams now declare a certificate in Git; it's issued, stored as a Kubernetes secret and renewed before expiry with no one touching it.

Certificate in Git→cert-manager
per namespace→requestVenafi
approval→signedKubernetes Secret→Ingress · services · Kafka

Qubo IoT cloud, built solo

Hero Electronix · AWS, HiveMQ, Kafka, Kinesis, Kubernetes, Terraform
AWS bill −30% · broker +40%
THE PROBLEM

Qubo, Hero Group's line of consumer IoT devices, had no cloud platform. Devices needed secure, always-on connections, and their data needed somewhere to go, from an empty AWS account.

WHAT I DID

Designed and built the whole platform myself and took it live: VPC, IAM, Cognito, API Gateway and Lambda; a clustered HiveMQ broker with authentication; Kafka, Kinesis and Firehose pipelines; Kubernetes with blue-green releases; infrastructure as code in Terraform, CloudFormation and Ansible. Then ran it, fixing crypto and code-path issues in the broker setup and trimming spend.

IoT devices→MQTT/TLSHiveMQ cluster→Kafka · Kinesis · Firehose→DynamoDB · MongoDB · Cassandra · RDS · Redis

Shared CI/CD for 150+ engineers

adidas · Jenkins (Groovy), GitHub Actions, Checkmarx, Harbor, Flux
Monorepo build time −50%
THE PROBLEM

Many teams, many pipelines, each a little different. Releases were slower and less safe than they needed to be, and a Lerna monorepo took far too long to build and test.

WHAT I DID

Built and maintain the Jenkins shared libraries and GitHub Actions workflows that developers and QA release through, with Checkmarx SAST as a gate, images in Harbor and Flux for GitOps deploys to EKS. Reworked the monorepo build so build and test time came down by about half.

Bitbucket→Jenkins / GitHub Actions→Checkmarx SAST→Harbor→Flux→EKS · dev → prod
